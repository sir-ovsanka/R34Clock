An animated desktop clock widget built with **C++** and **Qt 6**. It displays time using looping pixel-art GIF sprites of characters from the famous green site.
---
## ✨ Features
* **Frameless & Transparent UI**
* **Animated Digits:** Each digit is animated
* **Always on Top:** Stays pinned above all other open windows
* **Clean Taskbar:** Utilizes `Qt::Tool` so the widget does not clutter your OS taskbar.
